{# A6-ish UNIVERSAL share card -- 4-up on A4 landscape, 5mm sheet margin, 10mm middle gutters (= 2 x sheet margin). Universal as of Block 5b: prints for ANY ListingType (event, raffle, giveaway, rental, sale, service, training, auction, commission, offer). The skeleton is constant; two regions vary by type: - TYPE BADGE (top-right corner) -- color + label per type - DATA RIBBON (between description and QR) -- type-aware fields See lp-locandina-universal-share-artifact memory for the why. GEOMETRY MATH (Block 5c: 5mm sheet edges + 10mm middle gutters) The double-edge gutter rule: when N cards share a cut line, the gutter between them must equal 2 x the per-card border. Otherwise, after cutting, the cards get an asymmetric border (5mm on the outer edges, 3mm on the cut edge) which screams "amateur." Cutting DEAD CENTER of the 10mm gutter gives each card a clean SYMMETRIC 5mm frame on every side. A4 landscape = 297 x 210 mm sheet edges = 5mm on each side middle gutters = 10mm horizontal AND 10mm vertical (= 2 x edge) each card = (297 - 2*5 - 10) / 2 x (210 - 2*5 - 10) / 2 = (297 - 20) / 2 x (210 - 20) / 2 = 138.5 x 95 mm card positions (top, left): c1 = (5, 5) c2 = (5, 153.5) <- 5 + 138.5 + 10 = 153.5 c3 = (110, 5) <- 5 + 95 + 10 = 110 c4 = (110, 153.5) Cutting: 1 horizontal cut through y=105mm (dead center of the 10mm vertical gutter) 1 vertical cut through x=148.5mm (dead center of the 10mm horizontal gutter) -> 4 cards, each with a clean 5mm white frame on all sides. Inside-card vertical regions (87mm usable after 4mm padding top+bottom): header = 42mm (photo + title + byline-with-avatar + schedule) desc = 16mm (description block, see DESC_LIMIT in router) -- was 18mm ribbon = 6mm (type-aware data strip) qr-row = 23mm (real QR + scan-me + URL) total = 87mm The info-cell reserves padding-right: 22mm so a long title can't collide with the type badge that sits in the top-right corner. Block 3 design rules (still in effect): - Avatar INLINE with byline (option B). Never overlaid on the photo. - Background wash = cover image at 12% opacity, full-bleed. - Description: verbatim if <=250 chars, stub-truncated otherwise. WeasyPrint caveats we respect here: - @page sets paper size (NOT body/html dimensions). - margin: 0 on @page; we manage all whitespace in body padding. - CSS grid is partial in WeasyPrint -- avoided. - mm units throughout -- never px in print CSS. - Absolute positioning for outer card boxes, CSS tables for inside-card. Future Block 6 idea: the 10mm gutter is real estate, not waste -- watermark, crop marks, "Made on La Piazza" microcopy, timestamps. #} Locandina
